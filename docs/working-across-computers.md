# Работа с двух компьютеров

## Общие файлы

Публичный репозиторий: https://github.com/PavelUNOUN/ozon-agency-landing

На втором компьютере войдите в тот же GitHub-аккаунт и выполните:

```bash
git clone https://github.com/PavelUNOUN/ozon-agency-landing.git
cd ozon-agency-landing
```

Откройте именно папку `ozon-agency-landing` как локальный проект в Codex. Она должна быть основной рабочей папкой, чтобы Codex видел `AGENTS.md` и мог работать с Git. Перед работой: `git pull --ff-only`. После проверенного изменения: `git add` нужных файлов, `git commit`, `git push`. На другом компьютере снова `git pull --ff-only`. Для одновременной работы создавайте отдельные ветки.

Статус проекта, решения и следующие действия записываются в `docs/project-status.md`. Публичные статьи добавляются в `materials/`; ответы демонстрационного чата — в `knowledge/public-faq.json`.

## Как увидеть чаты с другого устройства

GitHub хранит файлы и коммиты, но не переписку Codex. Есть два способа продолжать работу:

1. **Существующий локальный чат:** подключитесь к исходному компьютеру через Remote / «Control other devices», если функция доступна для вашего аккаунта. Этот компьютер должен быть включён, онлайн и с запущенным приложением ChatGPT. Чат и файлы остаются на исходном компьютере; второй компьютер управляет задачей удалённо.
2. **Новые чаты без зависимости от включённого компьютера:** создайте Codex Cloud environment, выбрав этот GitHub-репозиторий, проверьте настройку и опубликуйте environment. Запускайте новый чат в режиме `Work in > Cloud` с этим environment. Такой чат можно открыть на другом поддерживаемом устройстве. Облачная задача не получает автоматически локальные файлы и входы в браузеры.

Обычная синхронизация ChatGPT Work — другая функция. Она не переносит локальные чаты Codex и не добавляет их в историю Codex. Само клонирование репозитория тоже не переносит старые чаты в приложение на втором компьютере. Для старых локальных чатов сохраняйте в репозитории итог: цель, решения, изменённые файлы, проверки и следующий шаг.

Официальная справка: https://learn.chatgpt.com/docs/remote-connections и https://learn.chatgpt.com/docs/environments/cloud-environments

## Что не публиковать здесь

Репозиторий публичный. Секреты, конфигурация рабочего бота, клиентские данные, внутренние отчёты и неутверждённые материалы держите отдельно в закрытом хранилище. Не копируйте сюда полные транскрипты чатов, если в них встречаются доступы или данные клиентов. Перед переносом больших локальных папок разберите их по содержимому и лицензиям.
