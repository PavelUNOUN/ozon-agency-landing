# Работа с двух компьютеров

## Общие файлы

Публичный репозиторий: https://github.com/PavelUNOUN/ozon-agency-landing

На втором компьютере войдите в тот же GitHub-аккаунт и выполните:

```bash
git clone https://github.com/PavelUNOUN/ozon-agency-landing.git
cd ozon-agency-landing
```

Откройте именно папку `ozon-agency-landing` как локальный проект в Codex. Она должна быть основной рабочей папкой, чтобы Codex видел `AGENTS.md` и мог работать с Git. Перед работой: `git pull --ff-only`. После проверенного изменения: `git add` нужных файлов, `git commit`, `git push`. На другом компьютере снова `git pull --ff-only`. Не редактируйте одну и ту же ветку одновременно на двух машинах без промежуточного push/pull; для параллельных задач создавайте отдельные ветки.

Статус проекта, принятые решения и следующие действия записываются в `docs/project-status.md`. Публичные статьи и материалы для сайта добавляются в `materials/`; ответы чата — в `knowledge/public-faq.json`.

## Чаты Codex

GitHub хранит файлы и коммиты, а не переписку Codex. Войдите в один и тот же аккаунт OpenAI на обоих компьютерах. Если в приложении доступна синхронизация новых задач через Work Cloud / Local computer access, включите её и создавайте **новые** чаты в нужном проекте. По официальной документации старые локальные задачи автоматически не становятся синхронизированными; сама синхронизация переписки не переносит локальные файлы на другой компьютер. Перед продолжением чата проверьте, к какой машине и папке он подключён.

Для уже существующих локальных чатов сохраняйте в репозитории краткий итог: цель, решения, изменённые файлы, проверки и следующий шаг. Не копируйте в публичный репозиторий полные транскрипты, если они содержат доступы или данные клиентов.

Официальная справка: https://learn.chatgpt.com/docs/projects

## Что не публиковать здесь

Репозиторий публичный. Секреты, конфигурация рабочего бота, клиентские данные, внутренние отчёты и неутверждённые материалы держите отдельно в закрытом хранилище. Перед переносом больших локальных папок разберите их по содержимому и лицензиям.
