# Состояние проекта

Обновлено: 11 ноября 2026 года.

## Что находится в этом репозитории

- `index.html`, `assets/`, `favicon.svg` — статический лендинг «Ритм кабинета».
- `materials/` — раздел будущих статей; стартовая страница пока закрыта от индексации.
- `knowledge/public-faq.json` и `assets/chat.js` — публичные ответы демонстрационного чата.
- `docs/chat-architecture.md` — проект архитектуры будущего API и базы знаний.
- `docs/working-across-computers.md` — порядок работы с разных компьютеров.
- `docs/growth-plan-2026-11-11.md` — поэтапный план развития сайта, канала и бота.
- `docs/social/` и `assets/social/` — тексты и обложки опубликованных постов агентства.

- Чат работает по локальному публичному FAQ, без модели и серверного API.

## Принятые границы

Публичный сайт и утверждённый контент храним здесь. Данные клиентов, ключи, логи, внутренние отчёты и неутверждённые материалы сюда не загружаем. Историю чатов не используем как единственное место для решений: ключевой итог записываем в этот файл.
