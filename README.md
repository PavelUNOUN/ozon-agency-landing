# Лендинг агентства Ozon

Статический черновик лендинга. Сборка и установка зависимостей не нужны.

## Запуск локально

Из корня репозитория:

```bash
python3 -m http.server 8000
```

Откройте `http://127.0.0.1:8000/`.

## Размещение на сервере

Скопируйте `index.html` и папки `assets/`, `knowledge/`, `materials/` в корневую папку сайта вашего веб-сервера. Главный файл должен открываться как `/index.html`. Проверьте, что `/knowledge/public-faq.json` отдаётся с типом `application/json`.

Внешние шрифты загружаются с Google Fonts. При необходимости их можно заменить локальными файлами.

## Что уже работает

- Кнопка Telegram ведёт к Павлу: `@Pavel_ozon_agency`.
- Раздел `/materials/` подготовлен для будущих статей. Пока он закрыт от индексации.
- Чат отвечает на базовые вопросы из `knowledge/public-faq.json`. Ответы можно обновлять в этом файле без правки логики `assets/chat.js`.

## Что пока демонстрационное

- Форма бесплатного аудита проверяет поля, но **не отправляет и не сохраняет заявки**.
- Чат пока не использует модель и серверный API. План подключения общей базы знаний для сайта и Telegram описан в `docs/chat-architecture.md`.
- Название агентства и реальные кейсы ещё не утверждены.

Перед использованием для привлечения клиентов подключите приём заявок и актуальные контакты, затем проверьте тексты и объём услуг.
