# Лендинг агентства Ozon

Статический лендинг «Ритм кабинета». Сборка и установка зависимостей не нужны.

Домен проекта: https://ritm-cabinet.ru/. На REG.RU файлы сайта лежат в `/www/ritm-cabinet.ru/`.

## Запуск локально

Из корня репозитория:

```bash
python3 -m http.server 8000
```

Откройте `http://127.0.0.1:8000/`.

## Размещение на сервере

Скопируйте `index.html`, `favicon.svg` и папки `assets/`, `knowledge/`, `materials/` в корневую папку сайта вашего веб-сервера. Главный файл должен открываться как `/index.html`. Проверьте, что `/knowledge/public-faq.json` отдаётся с типом `application/json`.

Внешние шрифты загружаются с Google Fonts. При необходимости их можно заменить локальными файлами.

## Что уже работает

- Кнопка Telegram ведёт к Павлу: `@Pavel_ozon_agency`.
- Форма аудита готовит текст сообщения и позволяет скопировать его для отправки Павлу в Telegram.
- Раздел `/materials/` подготовлен для будущих статей. Пока он закрыт от индексации.
- Чат отвечает на базовые вопросы из `knowledge/public-faq.json`. Ответы можно обновлять в этом файле без правки логики `assets/chat.js`.

## Что пока демонстрационное

- Форма **не отправляет и не сохраняет заявки автоматически**. Посетитель копирует подготовленный текст и отправляет его Павлу самостоятельно.
- Чат пока не использует модель и серверный API. План подключения общей базы знаний для сайта и Telegram описан в `docs/chat-architecture.md`.
- Название агентства и реальные кейсы ещё не утверждены.

Если нужен автоматический приём заявок, подключите серверный обработчик формы. Перед публикацией проверьте тексты и объём услуг.
